1. Membuat Environment:
    
    conda create -n env_dl python=3.10 -y

2. Mengaktifkan Environment:
    
    conda activate env_dl

3. Langkah 3: Install Library Deep Learning dan Jupyter

    conda install jupyter ipykernel pandas numpy matplotlib -y

    pip install tensorflow torch torchvision

4. Daftarkan Environment sebagai Kernel
    python -m ipykernel install --user --name=env_dl --display-name="Deep Learning"
